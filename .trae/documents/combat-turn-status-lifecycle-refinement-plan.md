# 战斗回合与状态生命周期细化计划

## Context
上一轮已统一四类战法、选敌、追击/被动响应不递归及指挥来源倒下清除效果。本轮聚焦尚不完整的行动队列、控制状态重复施加、持续伤害/治疗时点与数值快照，以及复合伤害效果的胜负检查边界；目标是让正文、流程图和28条静态战报遵循同一规则，不实现战斗模拟器或调整经济平衡参数。

## 已确认规则
- 每次选择下一名武将行动时，按当时实时速度，从尚未行动的存活单位中选择；速度变化不打断当前武将行动，影响之后的选择。同速沿用前锋→中军→后军的稳定顺序。
- 控制状态限定为震慑、缴械、沉默、封印。减速是速度修正，不属于控制；易伤/减伤、属性状态、持续伤害/治疗也不属于控制。
- 目标已有同名控制状态时，新施加失败，不刷新、不叠加，也不改变原效果；待旧状态消失后才可再次施加。
- 持续伤害/治疗的每跳数值在施加时计算并固定。技能声明该效果在目标行动前或行动后触发；施加后遇到的首个尚未经过的指定时点即可触发。每跳实际伤害不超过目标当前兵力，治疗不超过目标缺失兵力；倒下单位不被治疗。
- 持续伤害/治疗的来源若为指挥，指挥来源倒下时立即清除其全部存续效果，沿用既定规则。
- 直接攻击、由其明确绑定的吸血/自损/反伤作为同一原子效果，按效果声明顺序完成所有已触发子效果后统一检查胜负；若双方主将在该原子效果完成时均为0则判平。不会因此开启递归的追击或响应链。

## Proposed Changes

### Task 1：同步回合行动队列与胜负原子边界
- 修订第04章回合文字、表格和Mermaid图：回合开始时点效果后开始选择行动者；每次从尚未行动单位按实时速度选取，同速按站位；一个单位的主动及普攻流程完成后才选择下一单位。速度变化只影响之后的选择，不中断当前行动。
- 修订伤害结算与第08章胜负说明：明确攻击及技能显式绑定的吸血、自损、反伤属于同一原子效果，完整执行后再检查胜负；死亡不会取消该原子中已触发的其余绑定子效果。继续保留多目标同一伤害先统一扣兵、再复核胜负，以及同一原子效果双主将归零判平。
- 只将明确绑定在该原子效果中的子效果纳入；其它独立状态和后续效果仍逐原子检查胜负，结束后取消后续队列。

### Task 2：明确控制状态互斥与持续效果快照
- 修订第07章状态表及统一原则：列明四种控制状态；明确减速为独立速度修正。目标存在相同控制时，新施加无效，不刷新持续时间、不叠次数/强度；控制清除后才可重新施加。保留现有控制持续时长与阶段检查规则。
- 修订持续伤害/治疗规则：每跳效果值在施加时计算并固定；每个技能须声明按目标行动前或行动后触发。施加后若该指定时点尚未经过，则在本轮首次触发；否则等下一次指定时点。实际扣除/恢复分别以目标剩余兵力/缺失兵力为上限；死亡目标不再结算。指挥来源死亡时清除由其产生的所有剩余跳数。
- 同步第05章公式说明：每跳在施加时按来源兵力、来源属性、战法倍率、攻击侧修正，以及目标防御和受击修正预先计算并记录固定数值；触发时只按目标当前剩余兵力或缺失兵力封顶，不重新读取属性或增减伤、不重算效果值。
- 更新评审记录，记录动态队列、控制重复施加、持续效果触发/快照和复合原子胜负规则；不把减速误列为控制。

### Task 3：复核并修正28条静态战报
- 依现有角色兵力上限、伤害公式、固定触发结果和新效果时点，逐条核对事件顺序、攻击者当时兵力、目标兵力、理论/实际扣除、治疗缺失兵力上限及最终主将状态。
- 特别复核第1回合石魁先受韩策120和100后，其自身兵力为760/980；其后普攻系数必须取攻击者当时兵力。不得将目标的兵力或兵力上限误作攻击者当前兵力。发现差异后沿后续事件逐条传播修正。
- 保持28条事件、两回合固定触发和随机目标样例不变；只同步必要的文本及数值，不新增战报事件或模拟器。

## Assumptions & Decisions
- 速度排序以每次选择下一行动者为检查点；已开始行动的武将不被插断。平速站位顺序沿用现有前锋、中军、后军。
- 相同控制状态被拒绝时，既有状态的来源、时长和强度保持不变；不引入控制叠层或刷新规则。
- 持续效果预计算的是每跳固定效果数值；施加后的首个指定目标行动时点若尚未发生，可在施加回合触发。兵力不足/伤兵不足时按剩余可扣/可恢复量封顶。
- 指挥来源倒下立即清除其产生的持续效果；非指挥持续效果来源倒下后的现有规则保持不变。
- 吸血、自损、反伤只有在技能明确绑定同一伤害原子时才合并结算；原子完成后统一检查胜负，不扩大为递归响应。
- 不调整兵力下限、暴击倍率、战后伤兵比例等既有暂定平衡参数；不修改其它项目文件。
